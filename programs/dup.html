DUP (Daily Undulating Periodization)

1週の中で強度と rep/set を日ごとに変える方式。参考: 参考動画 (YouTube)

template

セルは「強度% x rep x set = 総負荷(% x rep x set / 100)」。計画の重量は max x % を 2.5kg 単位に丸めて算出。

強度ごとの rep x set

設計ルール

前提

  • repは3〜10repの範囲で行う。
  • 週2day、4週間で1サイクル。

組み方

  • 強度が高いときはrepが少なくsetが多い。強度が低いときはrepが多くsetが少ない。
  • S・B・Dをすべて行うので、3つとも重い日は作らない。各dayに高・中・低強度を1種目ずつ割り当てる。

総負荷

  • 総負荷 = 1RMの% x rep x set(÷100)。
  • 強度が違っても総負荷は基本的に同じになるようにする。
  • 強度が高い日の方が総負荷を微妙に少なくする(強度が上がるほど総負荷が単調に減る)。
  • 総負荷のゆらぎは20%以内(最小 ÷ 最大 ≧ 80%)に抑える。

重量の丸め

  • 最小単位は2.5kg。重量は max x % を2.5kg単位に丸める。
  • 丸め後の重量で総負荷(kg x rep x set)を計算し直し、種目ごとに「ゆらぎ20%以内」「強度が高いほど総負荷が少ない」を満たすか検証する(下の「ルールの検証」に表示)。

重量を上げる基準

DUPは日ごとに強度が変わるため、555のような「同じ重量を達成したら上げる」基準は使えない。そこで、サイクル(4週)の終わりに体感で次のmaxを決める。

おすすめ: 体感ベース

  • 4週が終わったタイミングで、各種目のmaxを見直す(サイクル中は重量を変えない)。
  • 判断は、最終週の高強度日(80〜85%)の最終セット後の余力で行う。
最終セット後の体感次サイクルのmax
あと3rep以上できた(楽)+5kg
あと1〜2rep できた+2.5kg
ギリギリ、またはフォームが崩れた維持
達成できないセットがあった維持、または -2.5kg

メモ

  • 上げ幅は種目で変えてよい(555ではDが+5kg、S・Bが+2.5kgだった)。
  • maxを実際に挙げて測る(maxテスト)方法もあるが、疲労とケガのリスクが大きい。この計画はmaxに対する%で組むため、正確なmaxは必須ではない。
  • 555の反省から、落とさず狙い続けず、維持や小さな減量も選ぶ。

ルールの検証

    メモ

    • 75%・55%は、整数のrep x setでは「単調に減る」「ゆらぎ20%以内」を両立できないため使わない。
    • 第2・3週の85%が連続する。Hの回数はS=3, B=3, D=2回。
